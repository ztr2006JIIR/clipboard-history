## Windows 安装版

下载下面附件中的 **ClipboardHistory-Setup-1.0.0.exe**，双击后按向导安装。安装完成后，从桌面或开始菜单的「历史粘贴板」启动即可，无需解压源码、安装开发工具或手动运行脚本。

- 适用于 Windows 10 / 11，依赖系统自带的 Windows PowerShell 5.1 和 .NET Framework 4.x。
- 默认仅为当前用户安装，不需要管理员权限；不会默认设置开机自启。
- 快速单独按两次 Ctrl 打开历史；支持图片/文字历史、搜索、图片矩阵缩放、多选及复制。
- 最近 30 天的历史保存在用户自己的电脑上。安装包不含作者的历史图片、文字、日志和设置。
- 更新前请从托盘菜单退出工具，再运行新安装包；覆盖安装保留历史。卸载程序不会主动删除历史数据。
- 修复搜索区域遮挡顶部图片的布局，并包含虚拟桌面唤起的改进。

**注意：** 当前安装包未进行商业代码签名，Windows 可能提示发布者未知或安全警告。请确认来自本仓库，不要关闭系统安全保护。SHA-256 校验值见同名 `.sha256` 附件。

不需要下载 GitHub 自动提供的 `Source code` 压缩包。安装版不会自动导入已有便携版文件夹里的历史记录。
